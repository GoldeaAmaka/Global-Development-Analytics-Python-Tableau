
# If the World Were 100 People — A Data Story of Humanity

## Project Overview

An end-to-end data analytics project using Python, Pandas and Tableau to explore global development trends across 217 countries and territories from 1990 to 2024.

The project transforms complex World Bank datasets into interactive visualisations, making it easier to understand how population, internet usage, electricity access, urbanisation, life expectancy, fertility and age distribution have changed over time.

## Problem Statement

Global development data is often spread across multiple datasets, making it difficult to compare countries, identify historical trends and understand differences in living conditions.

This project addresses that challenge by cleaning, integrating and analysing World Bank indicators and presenting the findings through accessible, interactive dashboards.

## Tools and Technologies

- **Python:** Data processing and analysis
- **Pandas:** Data cleaning, merging and transformation
- **Tableau:** Interactive dashboards and data storytelling
- **World Bank Open Data:** Source of development indicators
- **GitHub:** Project documentation and code sharing

## Data Analytics Workflow

1. Collected nine World Bank development indicators.
2. Cleaned and validated datasets using Python and Pandas.
3. Handled missing values and standardised data structures.
4. Merged datasets for country-level and historical analysis.
5. Applied population-weighted calculations where appropriate.
6. Prepared analysis-ready CSV files for Tableau.
7. Developed and published two interactive dashboards.

## Interactive Dashboards

### 1. Country Explorer

Allows users to select a country and year to explore:

- Total population
- Internet usage
- Electricity access
- Urban population
- Life expectancy
- Fertility rate
- Population distribution by age group

### 2. Global Overview

Visualises historical trends in population growth, internet usage, electricity access, urbanisation, life expectancy, fertility and age distribution.

## Data Source and Methodology

**Source:** World Bank Open Data — World Development Indicators (WDI).

**Coverage:** 217 countries and territories, 1990–2024.

Global indicators use population-weighted estimates where applicable. Missing values are handled according to data availability rather than being automatically treated as zero.

The global electricity-access trend begins in 2000 because earlier records have limited population coverage.
